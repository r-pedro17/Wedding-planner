# Wedding Planner V1 — Docs

Durable build context for the Wedding Planner application.

## Read order

1. `NORTH_STAR.md` — what the product is and what V1 includes.
2. `PRODUCT_SPEC.md` — how the product should behave.
3. `BUILD_PLAN.md` — the build sequence and proof points.
4. `ENGINEERING.md` — money, dates, Eve, UI, testing, and workflow rules.
5. `../AGENTS.md` — the short repo guide (project, commands, structure, conventions).

## Core rule

Build Dashboard + Budget + Planner + Eve as one usable V1.

Do not expand the scope until that complete user flow works.
