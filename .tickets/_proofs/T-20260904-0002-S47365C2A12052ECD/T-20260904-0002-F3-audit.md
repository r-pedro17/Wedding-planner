## Proof points (BUILD_PLAN.md F3)

All demonstrated by `tests/audit-convex.test.ts` (6 specs):

1. **Exactly-once per important successful mutation** — 5 mutations produce
   exactly 5 events, each `source: "ui"`, `actorKind: "user"`, correct
   entity/action/entityId.
2. **No event on a rejected mutation** — an authorization failure and a
   validation failure each leave 0 audit rows.
3. **Member-only read** — `api.audit.list` rejects unauthenticated
   ("Not signed in") and non-member ("You do not have access"); a member reads
   the history.
4. **No public API alters history** — no mutation is registered on the `audit`
   module (update/remove/delete/patch/edit all fail to resolve); the table is
   append-only by construction.
5. **UI caller cannot forge `source`** — `source` is never a mutation arg;
   passing `source: "eve"` is rejected, and every UI-path event is
   server-derived `"ui"`. The system (cron) path yields `"system"` with
   `actorKind: "system"` and no `actorId`.
